# Professional UI Update

This pass standardizes the application around a polished SaaS/startup visual system without changing roadmap functionality.

## Global
- Refined application background, typography hierarchy, focus states, form controls, surfaces, borders, shadows, and responsive spacing.
- Upgraded shared Button/Card/Input primitives.
- Refined global navigation, account controls, dropdowns, and mobile navigation.
- Added consistent dark-mode surface/typography handling.

## Page families
- Dashboard and utility pages now inherit the same product-grade surface and form treatment.
- Community/public discovery pages use a restrained premium hero, search surface, cards, and CTA system.
- Collaboration/team pages use consistent enterprise-style panels and calls to action.
- Authentication pages now have a dedicated branded product surface instead of a generic form card.
- Existing roadmap canvas visuals remain unchanged; the Create Roadmap canvas remains the canonical roadmap renderer.

## Functional behavior
No business logic, API contracts, roadmap synchronization behavior, or roadmap rendering architecture was intentionally changed in this UI-only pass.
