# Dark + Light Design Update

The application now uses a single premium SaaS color system in both modes.

- Light: cool white surfaces, ink typography, restrained blue primary, subtle borders and ambient gradients.
- Dark: blue-black surfaces, elevated cards, brighter blue primary, softened secondary text, and low-noise borders.
- Shared shadcn tokens (`background`, `foreground`, `primary`, `secondary`, `border`, `input`, `ring`, etc.) are now defined for both themes.
- Legacy slate/indigo utility usage is normalized globally so older pages do not visually drift from the new brand system.
- Roadmap canvas visuals remain canonical and are not replaced by the surrounding application palette.
